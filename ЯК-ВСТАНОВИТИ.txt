УКРАЇНСЬКИЙ АЛІАС — встановлення на iPhone та Android
=====================================================

Гра працює як веб-застосунок (PWA): відкривається за посиланням, додається на
початковий екран з іконкою, запускається на весь екран і працює без інтернету.

ВАЖЛИВО: саму папку чи файл через Telegram на iPhone не запустити — iPhone
показує HTML-файли лише в режимі перегляду, де ігри не працюють. Потрібне посилання.


КРОК 1. Розмістіть гру в інтернеті (один раз, безкоштовно)
-----------------------------------------------------------
Варіант А — GitHub Pages (посилання постійне):
  1. Зареєструйтесь на github.com.
  2. Створіть новий репозиторій (New repository), наприклад "alias", тип Public.
  3. "Add file" → "Upload files" → перетягніть УСІ файли з цієї папки
     (index.html, manifest.json, sw.js і папку icons) → "Commit changes".
  4. Settings → Pages → Branch: main, папка / (root) → Save.
  5. Через 1–2 хвилини з'явиться посилання на кшталт
     https://ваш-логін.github.io/alias/

Варіант Б — Netlify Drop:
  1. Відкрийте app.netlify.com/drop
  2. Перетягніть цю папку у вікно → отримаєте посилання.
  (Щоб посилання не зникло, може знадобитися безкоштовний акаунт.)

КРОК 3. Встановлення на iPhone
------------------------------
  1. Відкрийте посилання саме в SAFARI
     (у Telegram: натисніть на посилання → «Відкрити в Safari» / значок компаса).
  2. Натисніть «Поділитися» (квадрат зі стрілкою вгору).
  3. Оберіть «На початковий екран» → «Додати».
  4. На екрані з'явиться іконка «Аліас» — запускайте як звичайну гру.

Встановлення на Android
-----------------------
  Відкрийте посилання в Chrome → меню ⋮ → «Встановити застосунок»
  (або «Додати на головний екран»).


ОНОВЛЕННЯ ГРИ
-------------
Після змін завантажте нові файли туди ж і в файлі sw.js змініть
  const CACHE = 'alias-v1';   на   'alias-v2'   (v3, v4 ...),
щоб телефони підхопили нову версію.


ДОДАВАННЯ СЛІВ
--------------
Слова лежать у index.html у блоці <script type="application/json" id="word-db">.
Просто дописуйте слова в потрібний масив через кому в лапках.
